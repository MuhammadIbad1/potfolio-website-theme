# Portfolio Website Theme (Single-File HTML + Tailwind CSS)

A self-contained, zero-build developer portfolio theme for **Muhammad IBAD** built with **HTML5**, compiled **Tailwind CSS v4**, and **Vanilla JavaScript**.

## Included
- `index.html` — Single HTML file containing all layout sections, compiled Tailwind CSS, interactive hero particles, scroll parallax portrait & experience cards, 3D skills sphere, project category filters, single-page project case study modal, animated paper plane, and Web3Forms contact integration.
- `images/` — Portrait cutouts, project showcase mockups, noise texture, and Open Graph image.
- `favicon.svg` — `MI` brand icon.
- `User manual Assan Ilaaj (1).pdf` — Referenced by the Asaan Ilaaj case study modal.

## Usage
Open `index.html` directly in a browser or deploy all files to GitHub Pages, Netlify, Vercel, or shared hosting (`htdocs/`).
